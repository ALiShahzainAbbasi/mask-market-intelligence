A phase is DONE only when every checkpoint and its exit condition are met.
Partial code, a drafted plan, skipped tests, unavailable credentials, or an
unapproved numerical rubric are not completion.
Dependencies not yet reached are NOT_STARTED, not automatically BLOCKED.

For each applicable implementation checkpoint, completion includes:
- Implementation and safe error handling/logging.
- Unit tests and relevant integration/end-to-end or parser/evaluation tests.
- Lint and type checks.
- Migration for schema changes.
- Documentation and evidence of acceptance.
- No secrets, access-control bypass, or unapproved methodology changes.
If a check is not applicable, say why. If not run, say NOT RUN and why.
A checkpoint may only be closed with an explicit documented acceptance of
any permitted limitation; mandatory safety/methodology controls cannot be waived.
